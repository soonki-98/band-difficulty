# 건반 난이도 분석

## 1단계: 기술 데이터 추출

웹 검색으로 아래 항목을 파악한다. 확인 불가이면 "미확인"으로 표시.

- **비중**: 주요 악기인지 / 배경 패드(atmosphere)인지
- **멜로딕 파트** 존재 여부
- **아르페지오** 또는 독자적 코드 진행 여부
- 건반이 없거나 비중이 극히 낮으면 → **null**

## 2단계: 루브릭 대입

| 점수 | 기준 |
|------|------|
| null | 건반 파트 없거나 비중 매우 낮음 |
| 1~20 | 단순 코드 패드, 분위기용 |
| 21~40 | 단순 멜로디 또는 코드 진행 |
| 41~60 | 중요한 멜로딕/코드 파트, 적당한 기술 필요 |
| 61~80 | 복잡한 피아노 파트, 아르페지오, 독자적 멜로딕 역할 |
| 81~100 | 매우 복잡한 클래식 수준 피아노 파트 |

## 핵심 제약

1. **배경 패드 전용** → 1~20 이하
2. **아르페지오 또는 독자적 멜로딕 역할** 확인 시 최소 61
3. **null 판단 기준**: 곡 전반에서 건반 소리가 들리지 않거나 단순 스트링 패드 수준이면 null
