# 건반 난이도 분석

## 1단계: 기술 데이터 추출

아래 4개 쿼리로 웹 검색하여 항목을 파악한다. 확인 불가이면 "미확인"으로 표시.

**검색 쿼리 (4개 필수):**
1. `{곡명} {아티스트} piano cover tutorial beginner intermediate advanced` → 튜토리얼 레벨
2. `{곡명} {아티스트} piano sheet music difficulty synthesia` → Synthesia/악보 사이트 난이도 태그
3. `{곡명} {아티스트} keyboard piano part how to play` → 파트 구조 및 기법
4. `{곡명} {아티스트} piano arpeggio both hands octave` → 특수 기법 확인

**추출 결과를 아래 표로 정리한다:**

| 항목 | 확인 내용 |
|------|----------|
| 튜토리얼 레벨 | Beginner / Intermediate / Advanced / Expert / 미확인 |
| 건반 비중 | 주요 악기 / 보조 멜로딕 / 배경 패드 / 없음 |
| 연주 패턴 | 코드 패드 / 단선율 멜로디 / 아르페지오 / 양손 독립 / 고속 멜로딕 라인 |
| 특수 기법 | 옥타브 주법 / 트릴 / 크로스핸드 / 없음 |
| 튜토리얼 체감 | Easy / Medium / Hard / Very Hard / 미확인 |

## 2단계: 루브릭 대입

| 점수 | 기준 |
|------|------|
| null | 건반 파트 없음. 또는 단순 스트링/패드 레이어로 실제 건반 연주자 불필요 |
| 1~20 | 단순 코드 패드(2~4음 유지), 배경 분위기용. 오른손 단선율 최대 4분음표 단위 |
| 21~40 | 오른손 단선율 멜로디(8분음표 포함), 왼손 루트 또는 단순 코드 반주. 포지션 이동 거의 없음 |
| 41~60 | 오른손 멜로딕 라인 + 왼손 독립적 반주 패턴(8분음표 이상), 또는 간단한 아르페지오 포함 |
| 61~80 | 양손 독립 운지가 뚜렷하게 필요한 파트. 빠른 아르페지오, 옥타브 도약, 독자적 멜로딕 역할. 곡의 핵심 훅이 건반에 있음 |
| 81~100 | 양손 완전 독립 + 고속 패시지. 트릴·크로스핸드·복잡한 보이싱 조합. 클래식/재즈 훈련 수준 요구 |

## 핵심 제약

**제약 1: 튜토리얼 레벨 범위 제약 (외부 데이터)**

기타의 UG 태그 제약과 동일하게, 튜토리얼 레벨 또는 Synthesia 난이도가 확인된 경우 해당 범위를 준수한다:

| 튜토리얼 레벨 / 체감 평가 | 점수 범위 |
|--------------------------|----------|
| Beginner / Easy | 최대 30 |
| Intermediate / Medium | 21~55 |
| Advanced / Hard | 41~75 (최소 41 보장) |
| Expert / Very Hard | 최소 61 |

**제약 2: 기법 최소 점수**

기법이 확인되면 해당 최소 점수 이상으로 채점:

| 기법 | 최소 점수 |
|------|----------|
| 크로스핸드 / 복잡한 트릴 연속 | 최소 71 |
| 양손 완전 독립 + 고속 아르페지오 (16분음표 이상) | 최소 61 |
| 옥타브 도약 반복 / 아이코닉 멜로딕 리프 | 최소 51 |
| 양손 독립 (단순 아르페지오 포함) | 최소 41 |
| 오른손 단선율 8분음표 이상 멜로딕 라인 | 최소 21 |

**제약 3: null 판단 기준**

아래 중 하나에 해당하면 null:
- 곡 전반에서 건반 소리가 들리지 않음
- 스트링/패드 레이어가 있으나 독립적인 건반 연주자 파트가 없음 (DAW 프로그래밍 수준)
- 록 밴드 편성에서 기타가 건반 역할을 완전히 대체하고 건반 파트 별도 불필요

**제약 4: 상향 우선**

튜토리얼 레벨 범위와 기법 최소 점수 중 더 높은 값을 채택한다.

**제약 5: 직관 금지**

"밝은 J-POP", "쉬운 발라드" 등 일반 평판이 위 제약을 override하지 않는다. 배경 패드처럼 들려도 실제 악보에 아르페지오 파트가 있으면 기법 제약을 적용한다.
