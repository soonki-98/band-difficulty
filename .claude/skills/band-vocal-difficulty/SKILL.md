# 보컬 난이도 분석

## 1단계: 기술 데이터 추출

아래 5개 쿼리로 웹 검색하여 항목을 파악한다. 확인 불가이면 "미확인"으로 표시.

**검색 쿼리 (5개 필수):**
1. `{곡명} {아티스트} vocal range highest note`
2. `{곡명} {아티스트} original key singer octave range`
3. `{곡명} {아티스트} belting falsetto mixed voice technique`
4. `{곡명} {아티스트} cover vocalist difficulty review`
5. `{곡명} {아티스트} singing tutorial beginner intermediate advanced`

**추출 결과를 아래 표로 정리한다:**

| 항목 | 확인 내용 |
|------|----------|
| 최고음 | 노트명 (예: A4, B♭4, C5) 또는 미확인 |
| 음역 폭 | 옥타브 수 (예: 1.5옥타브) 또는 미확인 |
| 발성 기법 | 팔세토 / 믹스 보이스 / 강한 벨팅 / 없음 |
| 고음 지속 | 지속형 (2박 이상) / 순간형 / 없음 |
| 커뮤니티 체감 | Easy / Medium / Hard / Very Hard / 미확인 |

## 2단계: 루브릭 대입

| 점수 | 기준 |
|------|------|
| 1~20 | 단조로운 멜로디, 남성 F4 이하 / 여성 B4 이하, 음역 1옥타브 이내, 특별한 기교 없음 |
| 21~40 | 1~1.5옥타브, 보통 템포, 기초 호흡 필요, 주요 멜로디 명확 |
| 41~60 | 1.5~2옥타브, 남성 G4~A♭4 / 여성 C5~D♭5 내외 고음 일부, 가벼운 팔세토 또는 기초 믹스 보이스 |
| 61~80 | 고음 다수 (남성 A4~B4, 여성 D5~E5), 강한 팔세토 또는 벨팅 필요, 고음 지속 요구 |
| 81~100 | 극고음 (남성 C5+, 여성 F5+), 긴 고음 유지, 복잡한 멜리스마/런, 팔세토+벨팅 전환 |

> 참고 앵커:
> - Queen - We Will Rock You: ~15 (F3~E4, 극히 제한적 음역, 구호 수준)
> - Nirvana - Smells Like Teen Spirit: ~30 (B♭3~E♭5, 단순 멜로디, 중간 음역)
> - HAPPY (DAY6): ~45 (중간 음역, 밝은 발성, A4 내외)
> - 나는 나비 (YB): ~60 (록 창법, A4 내외 고음, 지속 고음 일부)
> - Pretender (Official髭男dism): ~82 (B4~C5 지속 고음, 섬세한 발성 기법)
> - 백일 (King Gnu): ~85 (C5+ 극고음, 팔세토+벨팅 전환, 복잡한 멜리스마)
> - Queen - Bohemian Rhapsody: ~90 (극고음, 광범위한 음역, 복잡한 멜리스마)

## 핵심 제약

**제약 1: 음역 밴드 제약 (최고음 기준)**

최고음이 확인된 경우 해당 음이 속하는 밴드를 반드시 충족한다:

| 최고음 남성 | 최고음 여성 | 최소 점수 |
|------------|------------|---------|
| F4 이하 | B4 이하 | (제약 없음) |
| G4~A♭4 | C5~D♭5 | 41 |
| A4~B♭4 | D5~E♭5 | 51 |
| B4 | E5 | 61 |
| C5 이상 | F5 이상 | 81 |

**제약 2: 발성 기법 최소 점수**

발성 기법이 확인되면 해당 최소 점수 이상으로 채점한다:

| 발성 기법 | 최소 점수 |
|---------|---------|
| 가벼운 팔세토 (짧게, 보조적) | 41 |
| 믹스 보이스 (곡 전반 활용) | 51 |
| 강한 팔세토 지속 / 고음 벨팅 | 61 |
| 극고음 지속 벨팅 (2박 이상) | 71 |
| 복잡한 멜리스마 / 런 | 61 |

**제약 3: 상향 우선**

음역 밴드 제약과 발성 기법 최소 점수 중 더 높은 값을 채택한다.

**제약 4: 직관 금지**

"쉬운 노래", "따라 부르기 좋은 곡" 같은 인상이 음역/기법 제약을 override하지 않는다.

## 코러스 (chorus) 별도 스코어링

보컬과 별개로 코러스 파트를 판단한다.

| 점수 | 기준 |
|------|------|
| null | 코러스 파트 없거나 비중 매우 낮음 |
| 1~20 | 단순 유니즌 백킹 보컬 |
| 21~40 | 기본 화음 (3도/5도), 쉬운 하모니 |
| 41~60 | 복잡한 하모니, 2~3파트 |
| 61~80 | 복잡한 하모니, 넓은 음역 필요 |
| 81~100 | 극도로 복잡한 보컬 하모니, 클래식 합창 수준 |

> 참고 앵커:
> - 대부분의 단순 밴드 코러스: ~15~20
> - HAPPY (DAY6): ~30 (기본 3도 화음)
> - 한국 록 밴드 합창: ~40
> - Queen - Bohemian Rhapsody (오페라 섹션): ~75
