# 보컬 난이도 분석

## 1단계: 기술 데이터 추출

웹 검색으로 아래 항목을 파악한다. 확인 불가이면 "미확인"으로 표시.

- **최고음** (노트명, 예: G4, B4, C5): `{곡명} {아티스트} vocal range highest note` 검색
- **팔세토 / 강한 벨팅** 필요 여부
- **멜리스마 / 런** (빠른 음정 이동) 여부
- **음역대** 추정 (옥타브 수)

## 2단계: 루브릭 대입

| 점수 | 기준 |
|------|------|
| 1~20 | 단조로운 멜로디, 음역 1옥타브 이내, 특별한 기교 없음 |
| 21~40 | 1~1.5옥타브, 보통 템포, 기초 호흡 필요 |
| 41~60 | 1.5~2옥타브, 남성 G4/여성 C5 내외 고음 일부, 적당한 발성 기교 |
| 61~80 | 고음 다수 (남성 A4~B4, 여성 D5~E5), 팔세토 또는 강한 벨팅 필요 |
| 81~100 | 극고음 (남성 C5+, 여성 F5+), 긴 고음 유지, 복잡한 멜리스마/런 |

> 참고 예시: 단순 팝 발라드 ~30 / 록 보컬 고음 다수 ~65 / Mariah Carey급 극고음 ~95

## 핵심 제약

1. **최고음이 확인된 경우** 해당 음이 속하는 밴드를 반드시 충족
   - 남성 A4~B4 또는 여성 D5~E5 → 최소 61
   - 남성 C5+ 또는 여성 F5+ → 최소 81
2. **팔세토/벨팅 필요** 확인 시 최소 61
3. **상향 우선**: 여러 기준 중 더 높은 밴드를 채택
4. **직관 금지**: "쉬운 노래"라는 인상이 음역 제약을 override하지 않음

## 코러스 (chorus) 별도 스코어링

보컬과 별개로 코러스 파트를 판단한다.

| 점수 | 기준 |
|------|------|
| null | 코러스 파트 없거나 비중 매우 낮음 |
| 1~20 | 단순 유니즌 백킹 보컬 |
| 21~40 | 기본 화음 (3도/5도), 쉬운 하모니 |
| 41~60 | 복잡한 하모니, 2~3파트 |
| 61~80 | 복잡한 하모니, 넓은 음역 필요 |
| 81~100 | 극도로 복잡한 보컬 하모니, 클래식 합창 수준 |
